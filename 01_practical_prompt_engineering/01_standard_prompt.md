# Standard Prompt

Direct question or instruction. No fancy, but we can get interesting content.

Even though, it is standard, doesn't mean we get wrong or short answers. But it often produces code with extra features, may contain bug, and doesn't provide enough specificity to get exactly what you need.

## Examples
```md
What color is the sky?
```

```md
Why is thunder so scary?
```

```md
Create a prompt library application that lets users save and delete prompts.

Users should be able to:
- Enter a title and content for their prompt
- Save it to localStorage
- See all their saved prompts displayed on the page
- Delete prompts they no longer need

Make it look clean and professional with HTML, CSS, and JavaScript.
```
